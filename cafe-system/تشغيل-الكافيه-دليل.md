# ☕ دليل تشغيل كابانا على جهاز الكافيه

## التشغيل اليومي (بضغطة واحدة)
دبل كليك على **`كابانا.bat`** → يفتح النظام فُل سكرين تلقائياً على المتصفح.
- بيشغّل الخادم في الخلفية + يفتح الواجهة كتطبيق (بدون شريط عناوين).
- للخروج من ملء الشاشة: `F11` — للإغلاق: `Alt + F4`.

## الإيقاف
دبل كليك على **`إيقاف-كابانا.bat`** (أو اقفل نافذة "كابانا-الخادم" المصغّرة أسفل الشاشة).

## اختصار على سطح المكتب
كليك يمين على `كابانا.bat` → **Send to → Desktop (create shortcut)** → غيّر اسمه لـ "كابانا".
(اختياري: نفس الاختصار حطّه في مجلد Startup عشان يفتح لوحده مع تشغيل الجهاز — اكتب `shell:startup` في Run والصق الاختصار هناك.)

## بيانات الدخول
- مدير: `admin` / `admin123`
- كاشير: `cashier` / `cashier123`
- باسورد التقارير (المدير): `1234`

## قبل الافتتاح — تنظيف بيانات التجربة
```
cd server
npm run reset
```
ده بيمسح كل الفواتير والشيفتات التجريبية ويصفّر المخزون — والمنيو والإعداد يفضلوا زي ما هم.
بعدها ادخلوا صفحة المخزون واعملوا **جرد**: أضيفوا كمية كل صنف الحقيقية.

## الطابعة
شوف ملف **`دليل-الطابعة.md`** — خلّي ماكينة الفواتير هي الطابعة الافتراضية ومقاس الورق 80مم.

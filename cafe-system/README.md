# ☕ نظام الكافيه (Café POS + Dashboard)

نظام متكامل لإدارة كافيه يعمل بنظام **الترابيزات والشيفتات**:

- **شاشة الكاشير (POS)** — كل ترابيزة لها فاتورة مفتوحة، الكاشير يضيف عليها الطلبات على مدار الجلسة، وعند الدفع (كاش) تُطبع الفاتورة وتتحرّر الترابيزة.
- **إدارة الشيفتات** — فتح الشيفت برصيد بداية الدرج، وقفله بجرد النقدية (المتوقع / الفعلي / الفرق).
- **المصروفات** — تسجيل أي مبلغ يخرج من الدرج (مشتريات/سحب) ويُخصم من حساب الشيفت.
- **إدارة المخزون** — متابعة كميات الخامات مع تنبيه عند النزول تحت الحد الأدنى.
- **لوحة تحكم للمدير** — مبيعات/مصروفات/صافي اليوم، الأكثر مبيعاً، سجل الفواتير والشيفتات.
- **إدارة المنيو** — إضافة/تعديل/إخفاء/حذف المنتجات.

> 💵 الدفع **كاش فقط** — بدون ضرائب. الإيصال بمقاس **طابعة حرارية 80مم**.

## 🧰 التقنيات

| الطبقة | التقنية |
|--------|---------|
| الواجهة (Frontend) | React 18 + Vite + React Router |
| الخادم (Backend) | Node.js + Express |
| قاعدة البيانات | SQLite (better-sqlite3) |
| المصادقة | JWT + bcrypt |

## 📂 الهيكل

```
cafe-system/
├── server/                # واجهة برمجية (API) + قاعدة البيانات
│   ├── src/
│   │   ├── index.js
│   │   ├── db.js          # المخطط والاتصال
│   │   ├── seed.js        # بيانات أولية
│   │   ├── auth.js        # JWT + الصلاحيات
│   │   └── routes/        # auth · menu · tables · orders · shifts · expenses · inventory · reports
│   └── data/              # ملف قاعدة البيانات (يُنشأ تلقائياً)
└── client/                # واجهة React
    └── src/
        ├── pages/         # Login · POS · ShiftPage · Expenses · Inventory · Dashboard · MenuManager
        └── components/    # Layout · Receipt
```

## 🚀 التشغيل

```bash
cd cafe-system
npm run setup    # تثبيت الكل + بيانات أولية + بناء الواجهة
npm start        # افتح http://localhost:4000
```
أو يدوياً: `server` ثم `npm install && npm run seed && npm start`، و`client` ثم `npm install && npm run build`.

### وضع التطوير
```bash
npm run dev:server   # الخادم على 4000
npm run dev:client   # الواجهة على 5173 (تُمرّر /api للخادم)
```

## 🔑 حسابات الدخول الافتراضية

| الدور | المستخدم | كلمة المرور |
|-------|----------|-------------|
| مدير  | `admin`  | `admin123`  |
| كاشير | `cashier`| `cashier123`|

> ⚠️ غيّر كلمات المرور و`JWT_SECRET` قبل الاستخدام الحقيقي.

## 🔄 سير العمل

1. الكاشير يسجّل الدخول ويفتح **شيفت** برصيد بداية الدرج.
2. من شاشة **الترابيزات** يفتح فاتورة لترابيزة ويضيف عليها الطلبات (تتراكم).
3. عند انتهاء العميل: **دفع كاش** → تُطبع الفاتورة وتتحرّر الترابيزة.
4. أي مصروف من الدرج يُسجّل في **المصروفات**.
5. نهاية الوردية: **قفل الشيفت** بعدّ النقدية → يظهر المتوقع/الفعلي/الفرق.

## 🖨️ طباعة الإيصال

الإيصال مُنسّق لمقاس **80مم** (`@page size: 80mm`). خلّي طابعة الإيصالات الحرارية هي الطابعة الافتراضية للجهاز، ولمّا تضغط "طباعة الإيصال" هيتطبع مباشرة عليها.

## 🌐 أهم مسارات الـ API

| الطريقة | المسار | الوصف |
|---------|--------|-------|
| POST | `/api/auth/login` | تسجيل الدخول |
| GET  | `/api/tables` | الترابيزات وحالتها |
| POST | `/api/orders/open` | فتح فاتورة لترابيزة |
| POST | `/api/orders/:id/items` | إضافة صنف للفاتورة |
| POST | `/api/orders/:id/pay` | دفع الفاتورة (كاش) |
| POST | `/api/shifts/open` · `/close` | فتح/قفل الشيفت |
| GET  | `/api/shifts/current` | ملخص الشيفت الحالي |
| GET/POST | `/api/expenses` | المصروفات |
| GET/POST/PUT | `/api/inventory` | المخزون |
| GET  | `/api/reports/summary` | ملخص لوحة التحكم (مدير) |

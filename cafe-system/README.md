# ☕ نظام الكافيه (Café POS + Dashboard)

نظام متكامل لإدارة كافيه، يتكوّن من:

- **شاشة كاشير (POS)** لتسجيل الطلبات وحساب الفاتورة والدفع وطباعة الإيصال.
- **لوحة تحكم للمدير** بإحصائيات المبيعات والأكثر مبيعاً وآخر الطلبات.
- **إدارة المنيو** لإضافة/تعديل/إخفاء/حذف المنتجات.

## 🧰 التقنيات

| الطبقة | التقنية |
|--------|---------|
| الواجهة (Frontend) | React 18 + Vite + React Router |
| الخادم (Backend) | Node.js + Express |
| قاعدة البيانات | SQLite (better-sqlite3) |
| المصادقة | JWT + bcrypt |

## 📂 الهيكل

```
cafe-system/
├── server/            # واجهة برمجية (API) + قاعدة البيانات
│   ├── src/
│   │   ├── index.js       # تشغيل الخادم
│   │   ├── db.js          # الجداول والاتصال
│   │   ├── seed.js        # بيانات أولية
│   │   ├── auth.js        # JWT + الصلاحيات
│   │   └── routes/        # auth / menu / orders / reports
│   └── data/          # ملف قاعدة البيانات (يُنشأ تلقائياً)
└── client/            # واجهة React
    └── src/
        ├── pages/     # Login / POS / Dashboard / MenuManager
        └── components/# Layout / Receipt
```

## 🚀 التشغيل

### 1) الخادم
```bash
cd server
npm install
npm run seed      # إنشاء بيانات أولية (مرة واحدة)
npm start         # يعمل على http://localhost:4000
```

### 2) الواجهة (وضع التطوير)
```bash
cd client
npm install
npm run dev       # يعمل على http://localhost:5173
```
في التطوير تُمرَّر طلبات `/api` تلقائياً إلى الخادم على المنفذ 4000.

### وضع الإنتاج (كل شيء من منفذ واحد)
```bash
cd client && npm install && npm run build
cd ../server && npm install && npm run seed && npm start
# افتح http://localhost:4000
```
عند وجود مجلد `client/dist` يقوم الخادم بخدمة الواجهة مباشرة.

## 🔑 حسابات الدخول الافتراضية

| الدور | المستخدم | كلمة المرور |
|-------|----------|-------------|
| مدير  | `admin`  | `admin123`  |
| كاشير | `cashier`| `cashier123`|

> ⚠️ غيّر كلمات المرور و `JWT_SECRET` قبل الاستخدام الحقيقي.

## 🌐 واجهة الـ API

| الطريقة | المسار | الوصف | الصلاحية |
|---------|--------|-------|----------|
| POST | `/api/auth/login` | تسجيل الدخول | عام |
| GET  | `/api/categories` | الأقسام | مسجّل |
| GET  | `/api/products` | المنتجات | مسجّل |
| POST/PUT/DELETE | `/api/products` | إدارة المنتجات | مدير |
| POST | `/api/orders` | إنشاء طلب | مسجّل |
| GET  | `/api/orders` | قائمة الطلبات | مسجّل |
| GET  | `/api/reports/summary` | ملخص لوحة التحكم | مدير |

الأسعار تُحسب في الخادم من قاعدة البيانات (لا يُعتمد على العميل)، والضريبة 14%.

# 🖥️ تجهيز جهاز الكافيه (ويندوز 7) — خطوة بخطوة

> ⚠️ **افحص الأول: الجهاز 32 ولا 64 بت؟**
> كليك يمين على «Computer» → «Properties» → شوف «System type»
> - **64-bit** ✅ كمّل عادي بالخطوات اللي تحت
> - **32-bit** ❌ للأسف النظام مش هيشتغل عليه — لازم ترقية لويندوز 10 (64-bit) أو جهاز تاني (أي جهاز من 2012 وطالع بـ 4 جيجا رام يكفي جداً)

---

## البرامج المطلوبة (نسخ محددة لويندوز 7 — متثبتش أحدث منها!)

| البرنامج | النسخة | لينك التحميل |
|----------|--------|---------------|
| **Node.js** | 16.20.2 (آخر نسخة تشتغل على Win7) | `https://nodejs.org/dist/v16.20.2/node-v16.20.2-x64.msi` |
| **Git** | 2.37.1 (آخر نسخة لـ Win7) | `https://github.com/git-for-windows/git/releases/download/v2.37.1.windows.1/Git-2.37.1-64-bit.exe` |
| **المتصفح** | Chrome 109 (آخر نسخة لـ Win7) أو Firefox ESR 115 | لو فيه Chrome على الجهاز غالباً هو 109 خلاص |
| **AnyDesk** | أي نسخة حالية (لسه بتدعم Win7) | `https://anydesk.com/download` |

> 💡 نزّل الملفات دي على فلاشة من جهازك وأنت رايح — أسهل من التحميل هناك.

## خطوات التثبيت (بالترتيب)

1. **ثبّت Node.js** — Next → Next → Finish (سيب كل الإعدادات الافتراضية)
2. **ثبّت Git** — Next على طول (كله افتراضي)
3. **ثبّت AnyDesk** — وسجّل الرقم اللي بيظهر (ده اللي هتدخل بيه عن بعد)
4. **نزّل المشروع**: افتح «Git Bash» من قائمة ابدأ واكتب:
   ```
   cd /c/
   git clone https://github.com/farminiogo-crypto/-.git cafe
   cd cafe/cafe-system
   git checkout claude/cafe-system-design-gpp6c1
   ```
5. افتح فولدر `C:\cafe\cafe-system` → دوس مرتين على **«تشغيل-كابانا»** (ملف الـ bat)
   - أول مرة هياخد 5-10 دقايق (بيحمّل مكتبات — محتاج نت المرة دي بس)
   - بعدها المتصفح هيفتح لوحده على البرنامج ✅
6. **اختصار على سطح المكتب**: كليك يمين على «تشغيل-كابانا.bat» → Send to → Desktop
7. **تشغيل تلقائي مع فتح الجهاز**: اضغط `Win + R` → اكتب `shell:startup` → Enter → انسخ الاختصار جوّه الفولدر اللي هيفتح

## الطابعة الحرارية
1. ثبّت درايفر الطابعة (من الـ CD بتاعها أو موقع الشركة)
2. خلّيها **الطابعة الافتراضية**: Control Panel → Devices and Printers → كليك يمين → Set as default
3. أول طباعة فاتورة: في نافذة الطباعة اختار مقاس الورق **80mm** والهوامش **None** — المرات الجاية هيفتكر لوحده

## ⚠️ ملاحظات مهمة لويندوز 7
- **متحدّثش** Node أو Git لنسخ أحدث — مش هتشتغل على Win7
- ويندوز 7 نفسه بقاله سنين من غير تحديثات أمان — **متخليش الجهاز ده يتستخدم في تصفح النت**، للكاشير بس
- **أول فرصة**: رقّي الجهاز لويندوز 10 — نفس الجهاز غالباً يستحملها، وساعتها كل حاجة بتبقى أسهل وأأمن

## النسخ الاحتياطي
البيانات كلها في `C:\cafe\cafe-system\server\data\`
- `cafe.db` = كل حاجة (فواتير، شيفتات، مخزون)
- `backups\` = نسخة تلقائية يومية من آخر 30 يوم
- **انسخ الفولدر ده على فلاشة كل أسبوع** كضمان إضافي
